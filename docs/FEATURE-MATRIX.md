# Matrice funzionale nativa

| Area | Moduli | Interazione |
|---|---|---|
| Disegno | Precision Pen, Fluid Sketch, Ink Studio, Width Studio | tool nel canvas |
| Geometria | Path Studio, Geometry Lab, Collision Align, Mirror Studio, Shape Reform | tool nel canvas |
| Proiezione | Projection Studio | quattro tool dedicati |
| Frattali | Fractal Grove | pannello con 12 cursori e generatore |
| Aspetto | Live Style, Color Lab, Texture Lab, Stipple Lab, Randomize | tool e gesto |
| Workflow | Smart Find, Vector Repair, Raster Lab, Auto Save | comando immediato |
| Sistema | Direct Settings, Suite Core | pannello nativo |

Tutte le funzioni appartengono a `VectorSuiteNative.aip`. Pannello e barra
strumenti condividono lo stesso catalogo e le stesse icone, generate da
`scripts/generate-assets.py` insieme a quelle dell'app di gestione.
